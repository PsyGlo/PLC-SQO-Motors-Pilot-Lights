# Credits & Academic Integrity

This repository contains technical implementations developed during advanced PLC programming studies.

### Academic Origin

*   **Platform**: LogixPro Simulator (Allen-Bradley RSLogix 500 compatible)
*   **Course**: PLC Sequencer Logic
*   **Instructor / Author**: LinkedIn Learning
*   **Reference**: [PLC Sequencer Logic](https://www.linkedin.com/learning/plc-sequencer-logic/)

### Scope of Work

The sequencer logic structure, exercise parameters, truth table, and functional requirements (motors + pilot lights sequence) are based on the teaching material from the LinkedIn Learning course.

My contribution to this repository includes:
*   **Implementation**: Complete ladder logic program using SQO instruction in LogixPro
*   **Enhancements**: Addition of both manual (push-button) and automatic (TON timer) modes
*   **Documentation**: Binary table configuration, visuals, and full project structure
*   **Reset Logic**: Proper handling of sequence reset at any point

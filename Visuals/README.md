# 📂 Visuals

This folder contains all screenshots and visual documentation of the **SQO Motors & Pilot Lights** project during development, testing, and demonstration in **LogixPro Simulator**.

---

### 📸 Content

| File                  | Description |
|-----------------------|-----------|
| IMG_1420.jpg          | Complete Ladder Logic program (LAD 2) showing SQO instruction, TON timer and Reset logic |
| IMG_1421.jpg          | I/O Simulator and BCD Simulator view with outputs (Motors + Pilot Lights) |
| IMG_1422.jpg          | Binary Table (B3:0) showing the truth table values for all 4 steps |
| (Future) Sequence_Diagram.png | Visual representation of the 4-step sequence |
| (Future) Running_Demo.gif     | Animated demonstration of the full sequence cycle |

---

### 🎯 Purpose

- Visual proof of correct **Sequencer Output (SQO)** instruction implementation
- Clear documentation of the binary file configuration (`B3:0`)
- Evidence of both manual (push-button) and automatic (timer-driven) operation
- Support material for academic presentation and evaluation
